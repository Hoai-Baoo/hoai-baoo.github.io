UVM (Universal Verification Methodology) = System Verilog + Framwork + Reusability/Scalability + Automation 
- **Industry standard** --> Mọi kĩ sư đều sử dụng chung 1 khái niệm, dễ dàng giao tiếp và làm việc
- **Framework** --> Cung cấp uvm base class như uvm_test, uvm_environment, uvm_sequencer, uvm_factory, uvm_analysis_port, ...
- **Reusability, Scalability** --> Được xây dựng dựa trên khái niệm hướng đối tượng nên dễ dàng reuse testbench và mở rộng.
- **Automation** Hỗ trợ random, coverage, regression testing

## **1. UVM Test Bench**

Một UVM test bench bao gồm các thành phần sau:


### **1.1. UVM Test**
- Kế thừa: uvm_test
- Mục đích:
  - Khởi tạo và chạy các sequence (scenario kiểm thử)
  - Configure environment và agent
  - Thiết lập các override (nếu cần)

```verilog
class user_test extends uvm_test;
  user_env env;

  `uvm_component_utils(user_test)

  function void build_phase(uvm_phase phase);
    env = user_env::type_id::create("env", this);
  endfunction

  task run_phase(uvm_phase phase);
    user_sequence seq = user_sequence::type_id::create("seq");
    phase.raise_objection(this);
    seq.start(env.agt.sequencer);
    #100;
    phase.drop_objection(this);
  endtask
endclass
```

### **1.2. Environment**

- Kế thừa: uvm_env
- Mục đích:
    - Gói gọn tất cả các agent, scoreboard, coverage collector
    - Không trực tiếp giao tiếp với DUT

```verilog
class user_env extends uvm_env;
  user_agent     agt;
  user_scoreboard sb;
  user_coverage  cov;

  `uvm_component_utils(user_env)

  function void build_phase(uvm_phase phase);
    agt = user_agent::type_id::create("agt", this);
    sb  = user_scoreboard::type_id::create("sb", this);
    cov = user_coverage::type_id::create("cov", this);
  endfunction

  function void connect_phase(uvm_phase phase);
    agt.monitor.item_collected_port.connect(sb.analysis_export);
    agt.monitor.item_collected_port.connect(cov.analysis_export);
  endfunction
endclass
```

### **1.3. Agent**

- Kế thừa: uvm_agent
- Có thể là:
  - Active agent: Có driver + sequencer → chủ động gửi dữ liệu
  - Passive agent: Chỉ có monitor → chỉ quan sát
 
 ```verilog
class user_agent extends uvm_agent;
  user_driver   drv;
  user_sequencer sqr;
  user_monitor  mon;

  `uvm_component_utils(user_agent)

  function void build_phase(uvm_phase phase);
    mon = user_monitor::type_id::create("mon", this);
    if (is_active == UVM_ACTIVE) begin
      drv = user_driver::type_id::create("drv", this);
      sqr = user_sequencer::type_id::create("sqr", this);
    end
  endfunction

  function void connect_phase(uvm_phase phase);
    if (is_active == UVM_ACTIVE) begin
      drv.seq_item_port.connect(sqr.seq_item_export);
    end
  endfunction
endclass
 ```

### **1.4. Driver**

- Kế thừa: uvm_driver #(T)
- Nhận transaction từ sequencer
- Gửi dữ liệu vào DUT thông qua virtual interface

```verilog
class user_driver extends uvm_driver #(user_transaction);
  virtual user_interface vif;

  `uvm_component_utils(user_driver)

  virtual function void build_phase(uvm_phase phase);
    if (!uvm_config_db#(virtual user_interface)::get(this, "", "vif", vif))
      `uvm_fatal("NOVIF", "Virtual interface not connected")
  endfunction

  task run_phase(uvm_phase phase);
    user_transaction req, rsp;
    forever begin
      seq_item_port.get_next_item(req);
      // Gửi tín hiệu vào DUT
      vif.data <= req.data;
      vif.valid <= 1;
      @(posedge vif.clk);
      vif.valid <= 0;
      seq_item_port.item_done();
    end
  endtask
endclass
```

### **1.5. Sequencer**

- Kế thừa: uvm_sequencer #(T)
- Nhận transaction từ sequence
- Gửi đến driver qua seq_item_port

```verilog
class user_sequencer extends uvm_sequencer #(user_transaction);
  `uvm_component_utils(user_sequencer)
endclass
```

### **1.6. Sequence**

- Kế thừa: uvm_sequence #(T)
- Định nghĩa các stimulus/transaction cần gửi, input cho sequencer
```verilog
class user_sequence extends uvm_sequence #(user_transaction);
  `uvm_object_utils(user_sequence)

  task body();
    user_transaction req;
    repeat(5) begin
      req = user_transaction::type_id::create("req");
      start_item(req);
      assert(req.randomize());
      finish_item(req);
    end
  endtask
endclass
```

### **1.7. Monitor**

- Kế thừa: uvm_monitor
- Theo dõi tín hiệu từ DUT
- Gửi transaction đến scoreboard hoặc coverage qua analysis port

```verilog
class user_monitor extends uvm_monitor;
  virtual user_interface vif;
  uvm_analysis_port #(user_transaction) item_collected_port;

  `uvm_component_utils(user_monitor)

  function new(string name, uvm_component parent);
    item_collected_port = new("item_collected_port", this);
  endfunction

  task run_phase(uvm_phase phase);
    user_transaction trans;
    forever begin
      @(posedge vif.clk);
      if (vif.valid) begin
        trans = user_transaction::type_id::create("trans");
        trans.data = vif.data;
        item_collected_port.write(trans);
      end
    end
  endtask
endclass
```

### **1.8. Scoreboard**

- Kế thừa: uvm_scoreboard
- Nhận dữ liệu từ monitor
- So sánh với kết quả kỳ vọng (reference model)

```verilog
class user_scoreboard extends uvm_scoreboard;
  uvm_analysis_imp #(user_transaction, user_scoreboard) analysis_export;

  `uvm_component_utils(user_scoreboard)

  function new(string name, uvm_component parent);
    analysis_export = new("analysis_export", this);
  endfunction

  function void write(user_transaction t);
    if (t.data == 8'hAA)
      `uvm_info("SB", "Pass: Expected data received", UVM_LOW)
    else
      `uvm_error("SB", "Fail: Unexpected data")
  endfunction
endclass
```

### **1.9. Coverage**

- Kế thừa: uvm_subscriber hoặc uvm_component
- Dùng covergroup để record coverage

```verilog
class user_coverage extends uvm_subscriber #(user_transaction);
  covergroup cg;
    coverpoint t.data {
      bins low = [0, 127];
      bins high = [128, 255];
    }
  endgroup

  `uvm_component_utils(user_coverage)

  function new(string name, uvm_component parent);
    super.new(name, parent);
    cg = new();
  endfunction

  function void write(user_transaction t);
    cg.sample();
  endfunction
endclass
```

### **1.10. Transaction**
- Kế thừa: uvm_transaction hoặc uvm_object
- Đại diện cho một giao dịch (packet, read/write, command…)

```verilog
class user_transaction extends uvm_sequence_item;
  rand bit [7:0] data;
  constraint c_valid { data != 8'h00; }

  `uvm_object_utils_begin(user_transaction)
    `uvm_field_int(data, UVM_DEFAULT)
  `uvm_object_utils_end
endclass
```
